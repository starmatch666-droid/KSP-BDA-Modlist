# FAR 简体中文补充

FAR Continued 自带 `Localization_zh-cn.cfg`，但仍有约 25 个 UI 字符串是英文。
本补丁是修正后的完整 `Localization_zh-cn.cfg` 副本。

## 安装

覆盖：

`GameData\FerramAerospaceResearch\Localization\Localization_zh-cn.cfg`

本机已经覆盖生效；FAR 更新后需要重新覆盖一次。

## 已补内容

- 稳定性导数导出按钮/错误提示
- 飞行日志、记录周期、刷新周期
- FAR 调试窗口与暴露分析
- 动态偏转、起始速度、衰减指数、最小控制量
- 载具边界、方向箭头、部件面积显示

保留未翻译的只有单位/符号/品牌名（CPU、GPU、Ixx、RealChute 等）。
