# ZZZ RSS Part Balance

给当前 Near Future、Far Future Technologies、Kerbal Atomics、CryoEngines、
CryoTanks、Tundra、BDB、OPT 等现有发动机与结构补丁做 RSS 尺度适配。

## 生效条件

- KSP 1.12.5
- 已安装 `RealSolarSystem`
- 未安装 `RealismOverhaul`

补丁使用 `NEEDS[RealSolarSystem,!RealismOverhaul]`，所以以后安装 RO 后会自动停用。
天线补丁叠加在 RSS 自带的 ×20 之上，并同时覆盖部件的升级版天线功率。

## 发动机标定基准

当前补丁不再使用独立的经验倍率，而是把原版 KS-25 和现实 RS-25 作为全局
发动机标尺：

| 指标 | 原版 KS-25（补丁前） | RS-25 目标 |
|---|---:|---:|
| 干质量 | 4.0 t | 3.526 t |
| 真空推力 | 1000 kN | 2279 kN |
| 真空 Isp | 315 s | 452.3 s |
| 海平面 Isp | 295 s | 366 s |

当前 246 个推进部件中有 192 个采用非吸气式推进剂，会应用这套标定；其余
54 个吸气式发动机使用下一节的 J58 标定。KSP 的海平面推力由 `maxThrust` 和 Isp 曲线共同决定，
因此现实 RS-25 的海平面、真空推力和两端 Isp 无法同时被单台 KSP 发动机完全
复现。这里优先匹配真空推力和两端 Isp，得到海平面推力约 1844 kN，比现实的
1860 kN 低约 0.9%。

## 喷气式标定基准

吸气式发动机以原版 J-X4“鞭梢”和 SR-71 使用的 J58 为整组标尺：

| 指标 | 原版 J-X4“鞭梢” | J58 目标 |
|---|---:|---:|
| 干质量 | 1.8 t | 2.721554 t |
| 台架海平面最大加力推力 | 130 kN | 151.239535 kN |
| 等效 Isp | 4000 s | 4000 s，保留不变 |

这里采用 J58 的未装机台架湿推力，因为 KSP 发动机部件不包含进气道和完整
安装损失。当前 4000 s 等效 Isp 已对应 J58 约 0.9 lb/(lbf·h) 的干态耗油率；
若改成 1.9 lb/(lbf·h) 的持续加力耗油率，等效 Isp 会降到约 1895 s，并会
显著破坏原版最关键的 Mach/高度推力曲线。因此本次只同步质量、最大推力和
单位推力对应的热输出，保留每台喷气机的 Isp、`velCurve` 与 `atmCurve`。

只含喷气模式的部件应用喷气质量倍率；同时具有火箭模式的组合发动机，其质量由
火箭部分的质量标定处理，避免两个质量倍率叠加。所有吸气模块的推力都单独应用
喷气倍率。

### 大型高涵道涡扇

大型商用高涵道涡扇不使用 J58 的最终倍率，而是以 GE90-115B 为基准单独校准。
以“歌利亚”的 4.5 t / 360 kN 为游戏侧样本，GE90 目标取约 8.8 t / 514 kN：

- 干质量：`8.8 / 4.5 = 1.955556×`
- 最大推力：`514 / 360 = 1.427778×`

当前覆盖：

- J-90“歌利亚” `turboFanSize2`
- J-90“达德利” `nfa-turbofan-25-1`
- GE-33“惠灵顿” `M3X_XLTurbofan`
- JE-8“水牛” `M3X_Turbofan`

这些部件先套用 J58 基础倍率，再应用 GE90 二次修正，因此最终倍率分别为质量
1.955556×、推力与热输出 1.427778×。“歌利亚”最终为 8.8 t、514 kN，推重比
58.41 kN/t。

J-593“阿卡迪亚”具有 Mach 2.1 包线和反推双模块，属于低涵道/加力高速机，
因此不使用 GE90 大涵道比标定；升力风扇和其他军用喷气机也保留 J58 基础组。

## 为什么这样做

只有抬高推力而不增加推进剂容量，不能真正增加 delta-v；只提高比冲又会让
发动机性能脱离原有设定。当前方案保留原版各发动机之间的相对设计取向，再用
RS-25 锚点校准整套数据。B9 可变燃料箱修改 `baseVolume`，普通储箱修改资源
容量。

## 安装

将整个 `ZZZ_RSS_PART_BALANCE` 文件夹放进：

```text
GameData\ZZZ_RSS_PART_BALANCE
```

不要与 Realism Overhaul 同时启用。已有飞船可继续载入，但旧储箱只提升上限，
建议在编辑器中重新加注推进剂后保存。

## 调整

只需要修改 `RSS_PartBalance.cfg` 最上面的 `RSS_PART_BALANCE` 节点。建议一次只改
一个倍率并测试：

- 起飞推力不足：先提高 `engineThrustMultiplier`
- 高轨 delta-v 不足：提高 `tankCapacityMultiplier`
- 发动机过热：提高 `radiatorCapacityMultiplier`，不要无限提高 `maxTemp`
- 核反应堆电量不足：提高 `reactorOutputMultiplier`
- 空天飞机升力不足：调整 `aircraftLiftMultiplier`
- 远日行星通信不足：提高 `antennaPowerMultiplier`
- 高速再入仍然烧毁：提高 `ablatorCapacityMultiplier`，不要先把热盾温度无限拉高

## 验证

1. 启动 KSP，让 ModuleManager 重建 `ModuleManager.ConfigCache`。
2. 检查 KS-25：应约为 3.526 t、2279 kN 真空推力、452.3 / 366 s Isp。
3. 检查 J-X4“鞭梢”：应约为 2.721554 t 和 151.239535 kN 最大推力。
4. 检查其他喷气机：最大推力统一乘 1.163381，Mach/高度曲线保持不变。
5. 检查“歌利亚”：应约为 8.8 t 和 514 kN 最大推力。
6. 检查燃料箱：同型储箱容量应约为原始值 3 倍。
7. 试飞 OPT、Mk2 或 Mk3 空天飞机，检查起飞距离和低速操控。
8. 试飞两级中型火箭至 LEO，再用带热盾的返回舱从 LEO 高速再入。
9. 检查高增益天线和至少两面中继天线的连接范围，验证地月及外行星通信。
10. 查看 `KSP.log` 中 ModuleManager 是否报告 `RSS_PART_BALANCE` 相关错误。

卸载时删除整个 `GameData\ZZZ_RSS_PART_BALANCE` 文件夹。
